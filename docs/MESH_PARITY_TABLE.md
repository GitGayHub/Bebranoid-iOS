# Таблица 1:1 сверки `HarmonoidMeshBackground.jsx` ↔ `HarmonoidMeshEngine.swift`

Проверка выполнена автоматически скриптом `scripts/verify-mesh-fixtures.mjs` (кросс-языковой запуск JS ↔ `swiftc` `scripts/dump-mesh-swift.swift`) на 7 эталонных буферах `64×64 RGBA` при `width = 430`, `height = 932`, `t = 0.0, 3.5, 7.0, 10.0s`.

## 1. Сверка констант и математических формул

| Параметр / Формула | Эталон (`HarmonoidMeshBackground.jsx`) | iOS (`Bebranoid/MeshBackground/HarmonoidMeshEngine.swift`) | Статус |
|---|---|---|---|
| Downscale обложки | `64 × 64` (`w = 64, h = 64`) | `analysisDimension = 64` (`64 × 64`) | 1:1 (Δ = 0) |
| Фильтрация пикселей | `a < 32`, `lum < 0.025 \|\| lum > 0.985`, `sat < 0.035` | `a < 32`, `lum < 0.025 \|\| lum > 0.985`, `sat < 0.035` | 1:1 (Δ = 0) |
| Hue-корзины | `Math.floor(hue / 10)` (`10°`, `0..35`) | `Int(floor(hsv.h / 10.0))` (`10°`, `0..35`) | 1:1 (Δ = 0) |
| Pastel boost | `lum > 0.55 && sat >= 0.04 && sat < 0.4 ? 1.35 : 1` | `lum > 0.55 && sat >= 0.04 && sat < 0.4 ? 1.35 : 1.0` | 1:1 (Δ = 0) |
| Вес пикселя (`score`) | `max(0.12, sat) * (0.45 + (1 - abs(lum - 0.42))) * pastelBoost` | `max(0.12, sat) * (0.45 + (1.0 - abs(lum - 0.42))) * pastelBoost` | 1:1 (Δ = 0) |

| Радиусы блобов `rad` | `max(w, h) * (0.55 + 0.08 * sin(t * 0.35 + i))` | `max(w, h) * (0.55 + 0.08 * sin(timeSec * 0.35 + Double(i)))` | 1:1 (Δ = 0) |
| Режимы наложения блобов | Блоб 0 `source-over`, блобы 1..3 `lighter`, стопы `0/0.95`, `0.45/0.45`, `1/0` | Блоб 0 `.normal`, блобы 1..3 `.plusLighter`, стопы `0/0.95`, `0.45/0.45`, `1/0` | 1:1 (Δ = 0) |
| Затемнение и виньетка | `12%` canvas + виньетка `0.22 / 0 (20..55%) / 0.28` + `.harmonoid-mesh__overlay` `0.18` | `12%` canvas + виньетка `0.22 / 0 (20..55%) / 0.28` + overlay `0.18` | 1:1 (Δ = 0) |
| Длительность перехода | `transitionMs = 1650` (мин. `1400 мс`), `smoothstep(0, 1, raw)` | `defaultTransitionMs = 1650.0` (мин. `1400.0`), `smoothstep(0, 1, raw)` | 1:1 (Δ = 0) |
